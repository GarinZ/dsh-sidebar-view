## 1. 参考实现摘要：dsh-go 的侧边栏是怎么组织的

源码位置（均相对 dsh-go 仓库根）：

| 文件 | 职责 |
|---|---|
| `app/lib/state/drawer_view_state.dart` | 全部视图状态：文件夹、排序、过滤、分块算法 |
| `app/lib/ui/shell/sessions_drawer.dart` | 抽屉整体布局（品牌行 / 搜索 / 作用域条 / 过滤条 / 列表 / 底栏） |
| `app/lib/ui/shell/drawer/drawer_list.dart` | 分块的渲染（置顶、文件夹、日期段） |
| `app/lib/ui/shell/drawer/drawer_filter_bar.dart` | 状态胶囊 |
| `app/lib/ui/shell/drawer/session_tile.dart` | 单行会话 |
| `app/lib/ui/shell/drawer/folder_sheets.dart` | 「对话列表」设置表、文件夹编辑 |
| `app/lib/ui/workspace/workspace_switcher.dart` | 顶部作用域切换条 |

### 1.1 一句话

**没有"两套视图"，只有一条会话列表**：顶部用"作用域"把范围切成"全部对话 / 某个工作区"，中间用固定优先级把会话分块（置顶 → 文件夹 → 按天），外加一行状态胶囊做筛选。工作区不是一种视图，而是一个**过滤器 + 新会话的落点**。

### 1.2 五段式布局（自上而下）

1. **品牌 + 新对话**（36dp 主按钮；多选时整行被选择头替换）
2. **搜索栏**
3. **作用域条**：`全部对话 ⌄` / `某工作区名 ⌄` + 行尾「对话列表」圆钮（排序、新建/管理文件夹、已归档、多选）
4. **状态胶囊行**：`全部` `运行中` `待确认 N` `未读 N`（可横向滚动，计数只给后两个）
5. **列表**：置顶段 → 文件夹段 → 今天 / 昨天 / 本周 / 更早
6. **底栏**：主机、网页版、设置（多选时换成动作条：移动 / 置顶 / 归档 / 删除）

### 1.3 分块算法（`drawerBlocks`，drawer_view_state.dart:666-733）

```text
排序键 keyOf(s) = sort == created ? 首事件时间(s) : updatedAt(s)
全部按 keyOf 倒序；时间戳相同用 sessionId 兜底（保证稳定）

若 filter != 全部：
    只返回一个「筛选块」= 命中项的平铺列表（不分文件夹、不分日期）
否则：
    块 1  置顶   = pinnedIds 中「不属于任何文件夹」的会话，按 pin 顺序
    块 n  文件夹 = view.folders 顺序；组内先置顶再按时间；作用域为单工作区时空文件夹隐藏
    块 k  日期   = 既不在文件夹、也不置顶的会话，按 sessionDayOf(keyOf(s)) 分桶
                   桶顺序固定：今天 / 昨天 / 本周 / 更早
```

**不变式：每条会话在列表里只出现一次**，归属优先级 = 文件夹 > 置顶 > 日期。

### 1.4 时间分桶（`sessionDayOf`，drawer_view_state.dart:466-487）

- 本地时区；**周一为一周起点**
- 用 `DateTime.utc(y,m,d)` 构造固定长度"日轴"做差，绕开 DST 的 23/25 小时日（docs/maintenance/drawer-calendar-dst.md）
- `diff <= 0` → 今天（**未来时间也算今天**，防止时钟偏差把会话甩到"更早"）
- `diff == 1` → 昨天；在本周一及之后 → 本周；否则 → 更早
- 桶标题用口语标签（今天/昨天/本周/更早），不写具体日期

### 1.5 排序（`DrawerSort`）

二选一，持久化：`最近活动`（updatedAt）/ `创建时间`（会话首事件时间，需异步补齐，见 session_created_state.dart）。切换排序时**分桶键跟着换**，不只是组内顺序变。

### 1.6 单行会话（session_tile.dart:17-90）

- 高 44；标题一行省略；当前会话有柔和底色
- 行尾**最多一个**标记：待确认/待回答（文字，警告色）> 运行中（呼吸点）> 未读（灰点）；置顶在文件夹内才显示小图钉
- 在文件夹内时内容缩进 30（与文件夹字形对齐）
- 多选模式：勾选圈从标题前滑入，整行点击 = 切换选中

### 1.7 交互

| 手势 | 行为 |
|---|---|
| 点会话 | 打开并关闭抽屉 |
| 长按会话 | 动作表：置顶/取消置顶、重命名、移到文件夹、分享、多选、归档（注明"进行中的一轮会停止"）、删除 |
| 点文件夹头 | 折叠/展开（状态持久化） |
| 长按文件夹头 | 在文件夹里新建对话 / 编辑（名称、颜色、emoji）/ 删除（可撤销，会话保留） |
| 多选 | 顶部选择头（全选/取消全选/退出）+ 底部动作条 |
| 筛选胶囊 | 切换筛选；筛选态下不显示分组，只显示命中项 |

**撤销**：归档走"先隐藏，撤销窗口结束后真正归档"；移动文件夹、删除文件夹都有撤销 toast。

### 1.8 持久化与只读降级

- 文件夹、排序：**本机** per-host，shared_preferences（`drawer.view.<kind>.<id>`）；上限 20 字符名、8 色调色板
- 置顶：走 **host 的 workspace registry**（`pinnedSessionIds`），跨端一致
- 归档：走 host
- 列表来自缓存/离线时进入 **readOnly**：禁止写操作，胶囊上的计数退化为状态文字

## 2. 我们要做的产品

### 2.1 设计原则

1. **一条列表，两个正交开关**：分组轴（工作区 / 时间 / 无）与作用域（全部 / 单工作区）分开，不做 N 套视图。
2. **会话是主语，工作区是属性**：平铺时工作区以"次级文本"出现在行上或分组头上，不再作为导航层级。
3. **不隐藏信息**：分块标题常显（含计数），不因为空就消失；空态给具体文案（没有运行中的对话 / 没有待确认的对话 / 没有未读对话）。

### 2.2 目标信息架构（Desktop 宽度）

```text
┌──────────────────────────────────────────────┐
│  DSH            [视图: 工作区 | 时间]  [搜索] │  ← 新建的一行：模式切换
│  全部对话 ⌄   〔运行中〕〔待确认 2〕〔未读 5〕 │
│  ──────────────────────────────────────────── │
│  ⌄ 置顶                                      │
│    ● 重构 session 订阅 …            dsh-plugins│  ← 平铺时行尾带工作区名
│  ⌄ 工作区 dsh-go                              │  ← 工作区分组头（count）
│    会话 A                                      │
│  ⌄ 今天                                       │
│    会话 B                                      │
└──────────────────────────────────────────────┘
```

## 3. 需求条目

优先级：P0 = 没它不能上线；P1 = 首版需要；P2 = 后续。

### R1 视图模式切换（P0）

- 在侧边栏顶部提供**分组轴切换**：`按工作区` / `按时间`（可扩展 `平铺` = 按时间且不显示工作区头）
- 切换即时生效，不刷新页面；当前模式持久化到本机
- 与 DSH 原生「视图选项 → 分组方式」（WorkSpace / Workspace Tree / In one list）互不冲突：本插件接管后，原生选项隐藏或在设置里跳转
- 验收：两种模式各来回切 5 次，列表内容不变、滚动位置不跳到别处、重启后保持

### R2 作用域切换：全部 ↔ 单工作区（P0）

- 顶部一条：`全部对话 ⌄` 打开工作区选择表（置顶的工作区优先 → 分组 → 其余，附「添加工作区」「管理工作区」）
- 选中某工作区 = 只显示它的会话；**新会话默认落在该工作区**
- 作用域与分组轴正交：单工作区 + 按时间 = 只有这一个工作区的会话按天分
- 验收：切到单工作区后列表只含该工作区会话，且新建会话进入该工作区；切回"全部对话"恢复

### R3 置顶段（P0）

- 集合来源：host 的 `pinnedSessionIds`（**跨端一致**，不要自建一份）
- 位置：列表最上方；**已归入用户分组的置顶会话不进置顶段**（只在组内置顶排序）
- 段标题常显：`置顶` + 计数；可折叠
- 验收：置顶/取消置顶立即生效；置顶会话在"按工作区"模式下仍显示在其工作区组内且排最前

### R4 用户分组 / 文件夹（P1）

- 一个会话最多属于一个分组；分组可命名（≤20 字符）、带颜色或 emoji、可折叠、可拖拽排序
- 入口：行菜单「移到分组」、多选动作条「移动」、设置表「新建分组 / 管理分组」
- 删除分组 = 仅解散，会话保留，**可撤销**
- 存储：本机 per-host（DSH host 没有分组概念，见 §6）
- 验收：新建 → 移入 → 折叠 → 重排 → 删除 → 撤销，全链路可用；重启后保持

### R5 时间分桶（P0）

- 桶：`今天` / `昨天` / `本周` / `更早`（首版固定这 4 个，不做"更早"再细分）
- 基准时间 = 当前排序键（updatedAt 或 createdAt），不是固定用 updatedAt
- 本地时区、周一为首日；实现必须用"日轴差值"而非 `Duration.inDays`，避免 DST 跨天错误
- 未来时间戳归入 `今天`
- 空桶不渲染；桶标题常显计数
- 验收：构造 今天 23:59 / 昨天 00:01 / 上周日 / 上上周 四条会话，桶归属正确；跨 DST 日验证（改系统时区到 America/New_York 复测）

### R6 状态胶囊（P0）

- 四枚：`全部` / `运行中` / `待确认` / `未读`
- `待确认` 与 `未读` 显示计数；计数为 0 时不显示数字（不显示 "0"）
- **筛选开启时列表退化为平铺命中列表**（不分置顶/分组/日期）——这是 dsh-go 的取舍，保持
- 筛选为空时给专属空态文案
- 筛选状态不持久化（刷新回到"全部"）
- 验收：跑一个会话 → 运行中 +1；让它停下来请求批准 → 待确认 +1、运行中 -1；点开 → 未读 -1

### R7 排序切换（P1）

- 两项：`最近活动` / `创建时间`；持久化
- 切换时**分桶键与分块顺序一起换**
- 验收：同一批会话在两种排序下桶归属可能不同，且与"最近活动"下一致地稳定

### R8 行内状态与平铺标记（P0）

- 行尾最多一个标记，优先级：待确认文字 > 运行中呼吸点 > 未读灰点
- 当前会话有底色
- **平铺/按时间模式下**，行尾（或标题下第二行）显示所属工作区名，用弱化色
- 验收：三种状态互斥不叠加；平铺模式下每行都能看出属于哪个工作区

### R9 多选与批量操作（P1）

- 进入：行菜单「多选」或列表设置表
- 动作：移动分组 / 置顶 / 归档 / 删除
- 折叠的分组里的会话**不参与"全选"**
- 验收：全选数量与可见行数一致

### R10 撤销与安全（P1）

- 归档：立即从列表移除，撤销窗口结束时才真正归档（并停止进行中的一轮）
- 删除会话：二次确认 + 无撤销（与 dsh-go 一致）
- 验收：撤销窗口内点撤销，会话原样回来

### R11 加载 / 空 / 离线（P1）

- 加载：骨架行（与真实行同栅格），不是转圈
- 列表未就绪时不"闪一下全部会话"再筛到单工作区（dsh-go 的 workspaceKnown 判断）
- 离线/缓存视图：只读；胶囊计数退化为状态文字

### R12 搜索（P2）

- 侧边栏内搜索框，标题即时匹配；命中时列表同样退化为平铺
- 可扩展"内容检索"（复用 host `sessions.search`）

### R13 键盘（P2）

- 上/下移动、Enter 打开、⌘F 搜索、Esc 退出筛选/多选

### R14 设置项（P2）

- 每段可独立开关（置顶 / 分组 / 时间桶）
- 分组轴默认值、排序默认值、时间桶粒度（4 档 / 细到具体日期）
- 已落地子集：视图选项里的字号三档（小 12px / 标准 14px 与原生标题一致 / 大 16px），档位同时决定行高 `24 / 28 / 32px` 与行间距 `1 / 2 / 3px`，工作区行与会话行共用同一套字号变量；以及「显示工作区名称」（仅单列表 / 按时间两处，按工作区不加）

### R15 外观：工作区图标与会话颜色（P2）

- 工作区可绑定一个前缀图标，两类：Emoji（按类别分组的网格）与线性图标（可搜索）；未设置时沿用原生文件夹图标，可一键恢复默认
- 会话可绑定九色之一，渲染为行首圆点；与运行状态点共用同一 16px 槽位，状态优先
- 两个选择器都从既有右键菜单进入（工作区「…」、会话「…」），不新增常驻入口
- 持久化在插件本地 `localStorage["dsh.workspace.view.sidebar-view.v1"]`（`workspaceIcons` / `sessionColors`），与别名一样按机器隔离、不跨设备同步
- 上限：记录最多 400 条，`emoji:<char>` / `icon:<name>` 形式，单个值不超过 32 字符

## 5. 与 DSH 原生侧栏的关系

- 原生已有「视图选项 → 分组方式：WorkSpace / Workspace Tree / In one list」「排序：Manual / Last updated」「筛选：隐藏归档 / 全部 / 仅归档」
- **不重复造**：归档筛选、工作区管理沿用原生；本插件专注 R1–R9
- 接管方式与已上架的第三方插件一致：占用 `sidebar.workspaces` 槽位，原生列表**隐藏但不卸载**，设置里可一键切回（参考 dsh-session-dates / dsh-session-view 的已知槽位名：`sidebar.workspaces`、`sidebar.workspaces.session.menu.item`、`sidebar.session.row.leading`、`uiWorkspace.openSession(sessionId)`）
- 冲突：同一时间只能有一个插件接管该槽位

## 6. 落地约束

1. **分组（文件夹）没有 host 侧载体**：DSH 的 `session/*` 只有标题，`workspace/*` 管目录/置顶/归档。所以分组只能存**插件本地**（浏览器 localStorage 或插件自有目录），并按机器隔离。跨设备不同步——需要在 UI 上说明。
2. **置顶必须复用 host 数据**（`pinnedSessionIds`），否则会与原生置顶互相打架。
3. **时间分桶依赖 host 给的 `updatedAt`**；"创建时间"需要额外一次批量取（会话首事件时间），要能降级。
4. **状态数据源**：运行中 = session.running；待确认 = 待审批/待回答交互；未读 = 完成未读（completionUnread）。三者都需实时订阅，不能靠轮询列表。
5. **性能**：597 条会话时只构建可见行（dsh-go 用 builder 惰性构建），筛选/多选变化不得触发全量行重建。
